### 02. Text-to-SQL AI Query System
**Natural Language to SQL Generation**

An AI-powered system that converts natural language questions into SQL queries.

- Fine-tuned Qwen2.5 using 4-bit QLoRA on 15K Text-to-SQL training pairs.
- Developed dynamic database schema introspection using SQLAlchemy.
- Built an AST-based SQL validation layer to prevent unauthorized database modifications and stacked injections.
- Implemented a React interface with multi-turn conversational capabilities and encrypted credentials.

**Stack:** Python • PyTorch • Hugging Face • Qwen2.5 • QLoRA • FastAPI • React • SQLAlchemy
